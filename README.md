# Bright Coffee Shop Sales Analysis

## Project Overview
This project analyses coffee shop sales data to uncover sales trends, evaluate business performance, and generate actionable insights. Completed as part of my BrightLearn Data Analytics learning journey.

Used SQL in Databricks to analyse transaction data and developed an interactive Looker Studio dashboard to communicate findings and business recommendations.

## Objectives
- Analyse sales performance using key performance indicators (KPIs).
- Identify best-selling products and product category trends.
- Explore sales patterns by day of the week and time of day.
- Understand purchasing patterns and business performance.
- Recommend improvements to inventory planning, staffing, and promotions.

## Tools and Technologies
- SQL — querying, aggregation, filtering, and analysis
- Databricks — data exploration and SQL analysis
- Looker Studio — interactive dashboard development
